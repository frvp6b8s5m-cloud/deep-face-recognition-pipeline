# Deep Face Recognition Pipeline

A comprehensive deep learning-based facial recognition pipeline with face detection, embedding extraction, similarity matching, and dataset utilities.

## Features

- **Face Detection**: MTCNN-based face detection with bounding box extraction
- **Face Alignment**: Landmark detection and face alignment
- **Embedding Extraction**: Deep face embeddings using ResNet50 or FaceNet
- **Similarity Matching**: Euclidean and cosine similarity-based face matching
- **Dataset Utilities**: Tools for dataset preparation, augmentation, and validation
- **Evaluation Metrics**: ROC-AUC, precision-recall, CMC curves
